# gh-updater documentation

gh-updater updates remote GitHub Actions references to stable commit pins.
It runs from a repository directory
and leaves review and commits to you.

| Need | Read |
| --- | --- |
| Install and perform a first update | [README](../README.md#install-and-run) |
| Preview updates and exclude pinned actions | [CLI examples](references/cli.md#examples) |
| Look up arguments and exit codes | [CLI reference](references/cli.md) |
| Understand the implementation and tool choices | [Architecture](explanations/architecture.md) |
| Set up development and run checks | [Contributing](../CONTRIBUTING.md) |
| Understand GitHub Actions validation | [Workflow inventory](../.github/workflows/README.md) |

This task/reference/explanation split follows the documentation approach of
[ai-prepare-commit-msg](https://github.com/electrocucaracha/ai-prepare-commit-msg/tree/main/docs).
The first-run example stays in the README;
additional recipes live alongside the CLI reference.
